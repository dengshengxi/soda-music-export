0开始之前：两件你必须知道的事

你的数据不会离开你的电脑。这个工具是一个纯网页，解析代码全部在你自己的浏览器里运行。 你选中的文件只被读进浏览器内存，不会被上传到任何服务器，页面一刷新就全部消失。 你可以断网使用（把页面存到本地再打开也完全可以）。
它读的是「本地缓存」，不是实时数据。汽水音乐客户端会把你看过的歌单内容缓存在本机。 所以——只有你在客户端里打开过的歌单，才导得出来。没打开过的歌单，本地根本没有数据，工具也变不出来。

支持哪些平台

系统缓存目录
Windows%APPDATA%\SodaMusic\Local Storage\leveldb
macOS~/Library/Application Support/SodaMusic/Local Storage/leveldb

手机端（Android / iOS）拿不到这个目录，暂时不支持。请在电脑上操作。

1三步上手

  1. 先在汽水音乐里打开你要导出的歌单 打开电脑上的汽水音乐，点进「我喜欢的音乐」或者你想导出的任意歌单，上下滚动一下让歌曲全部加载出来。 这一步很关键：客户端只有在加载时才会把数据写进本地缓存。看完之后不用退出，让它继续开着就行。
  2. 找到 leveldb 文件夹，把所有文件喂给工具 Windows 上按 Win+R，粘贴下面这行回车：
    Windows%APPDATA%\SodaMusic\Local Storage\leveldb
    macOS~/Library/Application Support/SodaMusic/Local Storage/leveldb
    打开的文件夹里通常有几十个文件（.ldb、.log、MANIFEST、LOG 等）。 不用挑，全选 —— 拖到工具页面上，或者点「选择 leveldb 文件夹」直接选中整个目录。工具会自动挑出有用的那些。
  3. 复制 / 下载，然后粘进 QQ 音乐 解析完成后页面会列出所有歌曲。调整好导出格式，点「复制导入文本」，再去 QQ 音乐粘贴即可（详细步骤见下）。
小提示：如果第 2 步里文件夹是空的或者不存在，说明汽水音乐装在了别的位置、或者用的是別的账号配置目录。 可以在资源管理器地址栏直接粘上面那行路径 —— 系统会自动把 %APPDATA% 展开成真实路径。

2选择歌单：不只是「我喜欢的音乐」

解析完成后，歌曲列表上方会出现一块「选择要导出的歌单」。客户端缓存里翻到的每一个歌单都会列在那儿，想导出哪个就勾哪个 —— 可以只勾一个，也可以一次勾好几个合并导出。

标签含义
我喜欢的你自己的「我喜欢的音乐」。默认帮你勾上。
我创建的你自己建的其他歌单，比如「开车听」「睡前」。
其他人的你打开过 / 收藏过的别人的歌单 —— 一样能导出，勾上就行。

旁边三个快捷按钮：

  • 全选 / 全不选 —— 一次勾上或清空。
  • 只要我创建的 —— 剔掉别人的歌单，只留自己的。

「合并时去重」

同时勾了多个歌单时，很可能有重复的歌（同一首歌既在「我喜欢的」又在「开车听」）。勾上这个开关，歌名 + 歌手完全相同的条目只保留第一条，导出的清单里不会有重复行。只勾一个歌单时它不起作用（单个歌单内部本来就已经去重了）。

想要的歌单列表里没有？回到汽水音乐把那个歌单点开、上下滚动让它加载完，再回来重新拖一次文件夹。 工具只能读到客户端已经缓存下来的东西，没打开过的歌单它变不出来。
数量对不上是正常的。有时歌单在服务器上标记 77 首，这里却导出 83 首 —— 多出来的是缓存里残留的历史条目（下架、失效、不同版本的都算）。 已一并保留，导入 QQ 音乐时匹配不上的会被自动跳过，不用手动删。

3导出格式：想不想带上歌手名，这里说了算

解析完成后，歌曲列表上方有一块「导出格式」设置区。改完立刻生效，右边的预览会同步更新。

选项作用效果示例
包含歌手名 默认开启。关掉就只导出纯歌名，一行一个。 晴天
晴天 - 周杰伦
包含专辑名 默认关闭。打开后会追加专辑。注意：专辑名会让 QQ 音乐的匹配率下降，一般不建议开。 晴天 - 周杰伦 - 叶惠美
加序号 在每行前面加 1. 2.……方便核对数量。 1. 晴天 - 周杰伦
分隔符 歌名和歌手之间用什么隔开。默认「空格 - 空格」，这是 QQ 音乐识别最好的一种。 晴天 - 周杰伦
晴天 周杰伦
晴天,周杰伦
每行顺序 「歌名 → 歌手」或「歌手 → 歌名」。有些平台用后者匹配更准。 周杰伦 - 晴天
要不要带歌手名？带歌手名 → 匹配更准，尤其重名歌曲（比如《起风了》有一堆版本）。 不带 → 文本最干净，适合贴进备忘录或者做纯歌单展示。 如果你要导入 QQ 音乐，建议保持默认的「歌名 - 歌手」。

搜索框会一起生效

如果你在上面的搜索框里搜了关键词，那么「复制 / 下载」导出的就是你当前看到的这批结果，而不是全部歌曲。 想导出全部，把搜索框清空再点复制。

4四种导出文件，各自适合什么

按钮内容什么时候用
复制导入文本纯文本，一行一首，按上面的格式设置直接粘进 QQ 音乐「导入外部歌单」
下载 .txt同上，存成文件留档、发给别人、稍后再用
下载 .csv表格，含 序号 / 歌曲名 / 歌手 / 专辑 / 来源歌单 / 歌曲ID 六列，UTF-8 BOM，Excel 直接打开不乱码要在 Excel 里筛选、统计、做二次处理
下载 .json结构化数据，字段完整给其他程序 / 脚本用

.csv 和 .json 始终包含完整字段，不受上面「是否带歌手名」的开关影响 —— 那组开关只管文本格式。

每个歌单卡片右上角还有单独的「复制 / 下载」按钮，可以只导出某一个歌单。

5导入 QQ 音乐

电脑端（QQ 音乐 PC 客户端）

  1. 打开 QQ 音乐 PC 版，左侧点「我的音乐」。
  2. 在歌单区域找一个入口叫 「导入外部歌单」（有的版本在歌单列表右键菜单里，或在「我的」页面右上角）。
  3. 把刚才复制的文本整段粘贴进去，点「开始匹配 / 导入」。
  4. 等它匹配完，会告诉你匹配成功多少首、失败多少首，确认创建歌单即可。

手机端

  1. 手机 QQ 音乐 → 「我的」 → 歌单区域 → 「导入外部歌单」（部分版本叫「一键搬家」）。
  2. 选择「粘贴文本」的方式，把文本粘进去（可以先在电脑上把 .txt 发到微信文件传输助手，再在手机上复制）。
  3. 等待匹配，创建歌单。
匹配不上的歌怎么办？这是正常的 —— 版权差异、歌曲下架、名字写法不同都会导致匹配失败。 QQ 音乐通常会把它们列出来，你可以手动搜一下补进歌单。实测几百首的歌单，匹配率一般在 80%~95% 之间。

6导入其他平台

  • 网易云音乐：PC 端「我的音乐」→ 收藏的歌单 → 也有「导入外部歌单 / 歌单搬家」入口，同样支持粘贴文本。
  • Apple Music / Spotify：官方没有粘贴导入，需要借助第三方工具（如 SongShift、TuneMyMusic）， 把下载的 .csv 传上去即可。
  • 只想留个清单：直接下载 .txt，扔进备忘录就行。

7常见问题

解析出来 0 首，提示「没有找到歌曲数据」

99% 是因为第 1 步没做：客户端只有在你打开歌单、歌曲真的加载出来之后，才会把内容写进本地缓存。

请回到汽水音乐，点进歌单，往下滚动几屏把所有歌曲都刷出来（看到底部为止），然后重新拖文件。

另外确认一下你拖的是 leveldb 这个文件夹里面的文件，而不是它的上一级 Local Storage。

歌单里显示 77 首，导出来 83 首 / 少了几首，哪个对？

都对，只是口径不同。歌单的「首数」是服务端统计的，本地缓存里可能包含已经下架、失效、或者你后来删掉但缓存还在的条目。

导入 QQ 音乐时，匹配不上的会被自动跳过，所以多一点没关系，不用手动删。

里面有别人的歌单 / 多出了我没收藏的歌单

工具默认只导出属于你账号的歌单（按歌单 owner 的 UID 过滤）。如果你换过账号登录、或者缓存里残留了别人的数据，理论上可能被带出来。

遇到这种情况，用搜索框或者每个歌单卡片单独的「复制 / 下载」按钮，只取你要的那个歌单就行。

歌名是乱码，或者出现奇怪的符号

本工具的解析器已经处理了常见的编码错位，正常情况不会出现。如果你真的看到了乱码，多半是这份缓存本身是残缺的（写入过程中客户端被强制退出会造成这种情况）。

解决：回到汽水音乐，重新打开一次歌单让它重新写入缓存，再重新拖一次文件。

为什么必须手动选文件夹？不能自动读吗？

浏览器的安全模型决定了：网页永远无法自己指定读取你硬盘上的某个路径，必须由你亲手选中。 这不是偷懒，恰恰是它安全的证明 —— 也正因为如此，它才不可能偷偷上传你的文件。

会被汽水音乐封号吗？有风险吗？

不会。整个过程不登录、不调用任何接口、不模拟请求，只是把你本机上已经存在的一份缓存文件读出来。 它和「用记事本打开一个文件」在性质上没有区别。

我的账号密码、登录凭证会被读到吗？

缓存里确实可能有 token 之类的字段，工具只提取歌曲相关的字段（歌名 / 歌手 / 专辑 / 歌曲ID）， 不会展示也不会保存其它内容。而且这些数据从头到尾没有离开你的电脑。

页面底部有个「原始数据」展开区，你可以自己查看被读到的全部记录，确认里面有什么。

关掉汽水音乐再操作会不会更好？

不用。这个工具对缓存文件是只读的，和客户端并行运行不会冲突，也不需要退出客户端。

可以一次导出多个歌单吗？

可以。只要这些歌单你都在客户端里打开过，一次拖入就会全部解析出来，页面上按歌单分卡片展示。 顶部的「复制导入文本」会把所有歌单合并成一份；想要单个歌单就用卡片上的按钮。

刷新页面后数据还在吗？

不在，这也是刻意设计的。所有内容只存在于浏览器内存里，刷新即清空，没有任何本地持久化，也没有服务端存储。

8原理：它是怎么读到的（技术向，可跳过）

汽水音乐的桌面端是 Electron 应用。Electron 的「Local Storage」在磁盘上其实是一个 LevelDB 数据库， 就在上面那个 leveldb 目录里。前端用的 react-query 会把接口返回的数据缓存进去，key 长这样：

_app://resources\x00\x01useRequestCache:playlist_detail:<歌单ID>

对应的 value 是一段 JSON，曲目在 data.media_resources[].entity.track_wrapper.track 里， 字段有 name、artists[].name、album.name。

所以这个工具做的事就是：解析 LevelDB 的 SSTable（.ldb）和日志（.log）→ 取出这些 key → 解 JSON → 按格式拼成文本。

两个实现上的坑，顺便记一下：

  • LevelDB 的 BlockHandle 里 size 不含 后面那 5 字节 trailer（[压缩类型][CRC32]）， 按「含 trailer」来切会整块解析失败。
  • 压缩类型 1 是 Snappy 而不是 zlib；而且 value 是 UTF-16 编码，偶尔还会错位 1 个字节， 需要对「偏移 0/1 × 大小端」四种组合都试一遍再挑最干净的那种。

10隐私与安全

  • 不上传：没有任何网络请求会携带你的文件数据。你可以打开浏览器开发者工具的 Network 面板全程验证。
  • 不存储：不使用 localStorage、不写 Cookie、不落盘，刷新即焚。
  • 不追踪：没有统计脚本、没有埋点、没有广告。
  • 只读：对你的缓存文件只做读取，不修改、不删除，也不会碰汽水音乐的安装目录。

如果你想更放心，还有一个终极用法：把这个页面的 index.html 和几个 .js 一起保存到本地， 断网后双击打开使用 —— 功能完全一样。

9另一条路：导出 QQ 音乐里的歌单

前面讲的都是从汽水音乐往外搬。反过来也能做一点 —— 把你在 QQ 音乐里的歌单抓出来。

先把话说清楚：这条路只能抓到页面上当前显示出来的歌，完整歌单导不出来。 QQ 音乐网页版不提供翻页，个人主页和歌单页只给前若干首（实测 10 首左右）； PC 客户端是原生 Qt 程序，本地歌单库 qmlist64.db 是加密的，读不了； 网页数据又是服务端直出（不发任何 XHR），连登录 Cookie 都是 HttpOnly，JS 读不到就没法自己调接口补齐。 这几条路都试过了，目前无解。如果你要的是完整歌单，别在这上面耗时间。

如果你只是想把眼前这几首抄下来，下面的办法能用 —— 在浏览器里登录 y.qq.com，用一个小书签抓取。

装一次（30 秒）

  1. 用你自己的 Edge / Chrome 打开 https://y.qq.com 并登录（一般扫码即可）。 这里说的就是你平时用的浏览器，不需要任何额外的窗口或软件。
  2. 把小书签拖到书签栏：打开工具站，切到「🎵 QQ 音乐（限可见）」，页面上有个绿色按钮 「⭐ QQ音乐歌单导出」 —— 按住它拖到地址栏下面那排书签里松手。
  3. 打开你要导出的歌单，比如左侧的「我喜欢的音乐」，或者任意一个歌单， 让歌曲显示出来。注意：它不会因为你往下滚就加载更多，页面上能看到多少，最后就只有多少。
  4. 点一下书签栏里那个 ⭐ —— 右上角会出现一个小面板，显示「已捕获 N 首」。

怎么用那个面板

  • 复制 —— 复制成「歌名 - 歌手」的纯文本，一行一首，和汽水那边的格式完全一样。
  • TXT / CSV / JSON —— 下载成文件，其中 CSV 带 BOM，Excel 打开不乱码。
  • 重新清空 —— 换歌单之前点它，不然几个歌单会串在一起。
  • 面板右上角的 × 只是收起来。想再叫出来，重新点一次书签就行。

书签拖不动？试试粘贴

在 QQ 音乐歌单页面按 F12 打开控制台（Console），把工具站上「复制脚本」按钮复制下来的代码粘进去，回车 —— 效果和书签一模一样。

控制台不让粘贴？Chrome / Edge 会弹红字提示防范诈骗。在那个输入框里先敲 allow pasting 回车， 再重新粘一次。这是浏览器自带的安全机制，不是脚本有问题。
每次刷新网页后要重新点一次书签（或重新粘一次代码）。因为抓取是挂在当时那个页面上的，刷新会把它清掉 —— 这也正是它用完就走、不留后门的原因。

常见问题

显示 0 首？先确认页面上的歌真的显示出来了。然后在页面上随便点一下、往下滚一点，再点 ⭐ —— 它是靠"页面自己收到的响应"记账的，页面没加载它就记不到。
数量比歌单里少？没滚到底。往下再滚一批就多加载一批，面板数字会跟着涨，涨到不动就是全了。
为什么不做成一个网址直接跑？浏览器不允许别的网站去读 QQ 音乐的登录数据（跨域限制），所以必须在你已经打开的 QQ 音乐页面上跑。 顺带这成了它最安全的一点：数据从头到尾没离开你的浏览器。
